# Changelog

## [Unreleased]

### Исправлено
- **Сборка:** `vfs.c` не компилировался и не линковался, хотя ядро
  вызывает `vfs_init()`/`vfs_type_name()` — это привело бы к ошибке
  `undefined reference`. Добавлено правило `vfs.o` в Makefile.
- **Сборка:** добавлен `msfs.c` (MSFS) с функциями `msfs_*`, на
  которые ссылается `vfs.c`. Без него линковка падала на
  `undefined reference to msfs_*`.
- **kernel.c:** добавлен `#include "fs.h"` — раньше VFS-функции
  вызывались без объявлений (implicit declaration при `-Wall -Wextra`).
- **FAT12:** `fat12_get`/`fat12_set` теперь корректно обрабатывают
  12-битные записи, пересекающие границу сектора FAT: значение
  дочитывается/дописывается в соседний сектор, а не обрезается.
  Сигнатуры функций изменены (`fat_start`, `fat_sectors`).

### Изменено
- **kernel.c:** команды `ls`, `cat`, `write` переведены с прямых
  вызовов `fat_*` на VFS-API (`vfs_ls`, `vfs_cat`, `vfs_write`).
  Теперь работает автоопределение ФС.
- Убраны лишние `extern`-объявления FAT из `kernel.c`.

### Добавлено
- `README.md` — описание проекта, зависимостей и сборки.
- `msfs.c` — собственная ФС MSFS (суперблок, inode, кластеры).

## [0.2.0-alpha] — 2025
- Расширенный сканер PCI, менеджер блочных устройств.
- Драйвер FAT12/FAT16 (чтение и запись).
- Слой VFS (`vfs.c`, `fs.h`).
- Оболочка: `help`, `clear`, `info`, `ver`, `echo`, `mystic`,
  `devices`, `pci`, `reboot`, `ls`, `cat`, `write`.

## [0.1.0]
- Первый загрузчик и минимальное ядро (VGA-вывод).
